# python-srcinfo

> [!WARNING]
>  This library has been deprecated.  Please see the
[`python-alpm`](https://alpm.archlinux.page/python-alpm/) project instead.

This is a small library to easily parse `.SRCINFO` files in python, using the python [parse](https://github.com/r1chardj0n3s/parse) library.

## Installing

If you're on Arch Linux, you can install this library from the [community] repository.
Alternatively, it can be installed from the PyPI using pip[^1].

[^1]: https://pypi.python.org/pypi/srcinfo
